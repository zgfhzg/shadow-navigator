# 그늘길 · Shadow
도보·자전거 경로를 출발 날짜와 시간대의 건물 그림자로 비교하는 웹 시뮬레이터.

## 실행
`npm run dev` → http://localhost:4173

## 검증
`npm test`

## 구현 범위
- 출발/도착 장소, 날짜, 시간 선택 및 역방향 탐색
- 도보/자전거별 통행 제약과 속도
- 최단/균형/그늘 우선 경로, 거리·소요 시간·그늘 비율·직사광선 노출 시간
- 시간대별 건물 그림자, 레이어 토글, 지도 확대/축소
- 반응형 화면 및 키보드 조작

## 모델과 한계
지도는 가상 100m 격자 도로망이며 실제 성수 지리가 아닙니다. 건물 치수·높이도 가상 데이터입니다. 선택한 도시/기기 위치의 위도·경도와 UTC 시각으로 계산한 근사 태양 위치로 건물 사각형을 투영하고 각 구간의 5개 지점에서 예상 통과 시각의 그늘을 샘플링합니다. 최단은 거리, 균형/그늘 우선은 이동 시간에 햇빛 노출 비용을 더한 단일 라벨 Dijkstra 근사 탐색입니다. 시간 의존 비용에 대한 전역 최적성을 보장하지 않습니다. 야간은 직사광선 없음으로 처리합니다. 도보 75m/분, 자전거 250m/분이며 자전거는 예제 공원 보행자 전용 구간을 제외합니다. 날짜/시각은 기기의 현지 시간대 기준입니다. 도시를 바꿔도 시각 입력의 시간대는 기기 기준으로 유지하며 UI에 IANA 시간대와 UTC 오프셋을 표시합니다.

실제 내비게이션, 실시간 GPS 안내, 장소 검색, 실시간 날씨, 건물/가로수 실측 자료는 아직 연결하지 않았습니다. 지도 음영은 출발 시각, 경로 통계는 구간별 통과 시각 기준입니다.

## 다음 단계
실제 건물 높이/형상 및 통행 속성이 있는 도로망 공급자를 선정하고, 지리 좌표 투영·정밀 태양 위치·공간 인덱스·시간 확장 경로 탐색을 적용합니다. 현장 그림자와 비교 검증 후 GPS 안내를 연결합니다.

## 현재 시간과 해외 시뮬레이션
- 초기 화면은 기기 현재 날짜·시간(분 단위)으로 시작하며 매분/탭 복귀 시 자동 갱신합니다.
- 직접 날짜·시간을 바꾸면 선택 모드로 전환하고, 지금 버튼으로 자동 갱신에 복귀합니다.
- 00:00~23:59를 지원합니다. 자정/날짜 변경 및 경로 진행 중 서머타임 전환은 UTC 경과 시간으로 처리합니다.
- 서머타임 시작으로 존재하지 않는 수동 선택 시각은 거부합니다. 반복되는 수동 선택 시각은 브라우저 Date 규칙에 따라 앞쪽 시각을 사용합니다. 현재 시간 모드는 실제 UTC 시각을 보존합니다.
- 서울/도쿄/런던/뉴욕/시드니 및 명시적으로 허용한 내 위치를 태양 계산에 사용합니다. 위치는 기기 메모리에서만 사용하며 서버에 보내거나 저장하지 않습니다.
- 모든 지역은 동일한 가상 도로/건물을 사용합니다. 해외 실제 경로 안내나 국가별 지도 데이터 연결은 미구현입니다.
- 태양 계산: [NOAA General Solar Position Calculations](https://gml.noaa.gov/grad/solcalc/solareqns.PDF). 대기 굴절은 제외한 근사치입니다.
