# 그늘길 · Shadow
도보·자전거 경로를 출발 날짜와 시간대의 건물 그림자로 비교하는 웹 시뮬레이터.

## 실행
`npm run dev` → http://localhost:4173

## 검증
`npm test`

## 구현 범위
- 출발/도착 장소, 날짜, 시간 선택 및 역방향 탐색
- 도보/자전거별 통행 제약과 속도
- 최단/균형/그늘 우선 경로, 거리·소요 시간·그늘 비율·직사광선 노출 시간
- 시간대별 건물 그림자, 레이어 토글, 지도 확대/축소
- 반응형 화면 및 키보드 조작

## 모델과 한계
지도는 가상 100m 격자 도로망이며 실제 성수 지리가 아닙니다. 건물 치수·높이도 가상 데이터입니다. 선택한 도시/기기 위치의 위도·경도와 UTC 시각으로 계산한 근사 태양 위치로 건물 사각형을 투영하고 각 구간의 5개 지점에서 예상 통과 시각의 그늘을 샘플링합니다. 최단은 거리, 균형/그늘 우선은 이동 시간에 햇빛 노출 비용을 더한 단일 라벨 Dijkstra 근사 탐색입니다. 시간 의존 비용에 대한 전역 최적성을 보장하지 않습니다. 야간은 직사광선 없음으로 처리합니다. 도보 75m/분, 자전거 250m/분이며 자전거는 예제 공원 보행자 전용 구간을 제외합니다. 날짜/시각은 선택한 도시의 현지 시간대 기준이며 UI에 IANA 시간대와 UTC 오프셋을 표시합니다.

기본 시뮬레이션에는 실제 내비게이션, GPS 안내, 실시간 날씨를 연결하지 않았습니다. 실제 지도 연결 화면의 구현 상태는 아래를 참고하세요. 지도 음영은 출발 시각, 경로 통계는 구간별 통과 시각 기준입니다.

## 다음 단계
실제 건물 높이/형상 및 통행 속성이 있는 도로망 공급자를 선정하고, 지리 좌표 투영·정밀 태양 위치·공간 인덱스·시간 확장 경로 탐색을 적용합니다. 현장 그림자와 비교 검증 후 GPS 안내를 연결합니다.

## 현재 시간과 해외 시뮬레이션
- 초기 화면은 서울의 현재 날짜·시간(분 단위)으로 시작하며 매분/탭 복귀 시 자동 갱신합니다.
- 직접 날짜·시간을 바꾸면 선택 모드로 전환하고, 지금 버튼으로 자동 갱신에 복귀합니다.
- 00:00~23:59를 지원합니다. 자정/날짜 변경 및 경로 진행 중 서머타임 전환은 UTC 경과 시간으로 처리합니다.
- 서머타임 시작으로 존재하지 않는 수동 선택 시각은 거부합니다. 반복되는 수동 선택 시각은 브라우저 Date 규칙에 따라 앞쪽 시각을 사용합니다. 현재 시간 모드는 실제 UTC 시각을 보존합니다.
- 서울/홍콩/도쿄/오사카/교토/런던/뉴욕/시드니 및 명시적으로 허용한 내 위치를 태양 계산에 사용합니다. 위치는 기기 메모리에서만 사용하며 서버에 보내거나 저장하지 않습니다.
- 기본 시뮬레이션의 모든 지역은 동일한 가상 도로/건물을 사용합니다. 별도의 실제 지도 화면은 API 키 설정이 필요합니다.
- 태양 계산: [NOAA General Solar Position Calculations](https://gml.noaa.gov/grad/solcalc/solareqns.PDF). 대기 굴절은 제외한 근사치입니다.

## 홍콩·일본 / 실제 지도 연결 준비
시뮬레이션에서 도시를 선택하면 그 도시의 시간대로 표시합니다. 홍콩 `Asia/Hong_Kong`(UTC+8), 도쿄·오사카·교토 `Asia/Tokyo`(UTC+9). 현재 시간은 자동 갱신하며, 수동 선택 후 도시를 바꾸면 같은 UTC 출발 순간을 보존합니다. 내 위치는 기기 시간대를 사용합니다.

Node.js 22.9 이상에서 실행합니다:

```sh
cp .env.example .env
# .env에 MAPTILER_KEY, GRAPHHOPPER_KEY 입력
npm run dev
```

http://localhost:4173/live.html 에서 MapLibre GL JS + MapTiler 지도/검색, GraphHopper 도보/자전거 후보 경로, 로컬 Overture 건물 GeoJSON 표시를 연결합니다. API 키가 없어도 기본 시뮬레이션은 동작합니다. 실제 지도 화면은 키 미설정/오류를 명시하며 가상 데이터를 실제 경로로 표시하지 않습니다.

- MapTiler 키는 브라우저에서 공개되는 키입니다. 허용 도메인과 사용량 제한을 설정하세요. 검색은 Node 서버를 경유합니다.
- GraphHopper 키는 서버 환경 변수에만 둡니다. `.env`는 Git에 포함되지 않습니다.
- MapLibre는 고정 버전 5.6.1을 CDN에서 로드합니다. 지도에는 공급자 attribution을 유지합니다.
- 건물 설치 방법: [data/README.md](data/README.md). 데이터는 아직 다운로드하지 않았습니다.
- **실제 건물 기반 그림자 계산, 후보 경로의 그늘 평가, GPS 안내는 아직 미구현입니다.** GraphHopper의 일반 대안 경로가 그늘 최적 경로라는 의미는 아닙니다.
- 실제 키를 이용한 공급자 통합 검증은 키 발급 후 필요합니다. 현재 테스트는 모의 공급자 응답과 로컬 HTTP 서버로 수행합니다.
- 기존 Sites는 정적 호스팅이며 이 Node API 서버를 실행하지 않습니다. 이번 GitHub 푸시는 배포가 아닙니다. API 호스팅과 인증/사용량 제한을 갖춘 배포 구성이 별도로 필요합니다. 개발 서버는 localhost에만 바인딩합니다.

공식 문서: [MapTiler](https://docs.maptiler.com/cloud/api/) · [GraphHopper](https://docs.graphhopper.com/openapi/routing) · [Overture](https://docs.overturemaps.org/getting-data/overturemaps-py/)
