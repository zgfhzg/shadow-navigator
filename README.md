# 그늘길 · Shadow
도보·자전거 경로를 출발 날짜와 시간대의 건물 그림자로 비교하는 웹 시뮬레이터.

## 실행
`npm run dev` → http://localhost:4173

## 검증
`npm test`

## 구현 범위
- 출발/도착 장소, 날짜, 시간 선택 및 역방향 탐색
- 도보/자전거별 통행 제약과 속도
- 최단/균형/그늘 우선 경로, 거리·소요 시간·그늘 비율·직사광선 노출 시간
- 시간대별 건물 그림자, 레이어 토글, 지도 확대/축소
- 반응형 화면 및 키보드 조작

## 모델과 한계
지도는 가상 100m 격자 도로망이며 실제 성수 지리가 아닙니다. 건물 치수·높이도 가상 데이터입니다. 서울 위도와 근사 태양 위치로 건물 사각형을 투영하고 각 구간의 5개 지점에서 예상 통과 시각의 그늘을 샘플링합니다. 최단은 거리, 균형/그늘 우선은 이동 시간에 햇빛 노출 비용을 더한 단일 라벨 Dijkstra 근사 탐색입니다. 시간 의존 비용에 대한 전역 최적성을 보장하지 않습니다. 야간은 직사광선 없음으로 처리합니다. 도보 75m/분, 자전거 250m/분이며 자전거는 예제 공원 보행자 전용 구간을 제외합니다. 날짜/시각은 서울 현지 시각 기준입니다.

실제 내비게이션, GPS, 장소 검색, 실시간 날씨, 건물/가로수 실측 자료는 아직 연결하지 않았습니다. 지도 음영은 출발 시각, 경로 통계는 구간별 통과 시각 기준입니다.

## 다음 단계
실제 건물 높이/형상 및 통행 속성이 있는 도로망 공급자를 선정하고, 지리 좌표 투영·정밀 태양 위치·공간 인덱스·시간 확장 경로 탐색을 적용합니다. 현장 그림자와 비교 검증 후 GPS 안내를 연결합니다.

## 디자인 v2 · 로컬 전용
화이트/차콜 기반과 코발트 블루 포인트, 지도 중심 레이아웃, 반투명 지도 조작부, 시스템 폰트, 벡터 아이콘을 적용했습니다. 축소 모션 설정과 모바일 화면을 지원합니다. 사용자 요청으로 자동 배포 및 호스팅 소스 동기화를 중단했습니다. 기존 사이트 중단 여부는 별도 확인해야 합니다.
