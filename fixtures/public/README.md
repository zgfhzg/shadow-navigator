# Public experience snapshot

OpenStreetMap road graph and Overture Maps buildings for the Hong Kong Central prototype. These are public source data, not user locations. Source, license, collection bounds and timestamps are retained inside the JSON. Buildings retain source records and the original SHA256 metadata. Attribution: https://www.openstreetmap.org/copyright and https://docs.overturemaps.org/attribution/ (ODbL).

This snapshot is committed so the static deployment can be reproduced without credentials or a live data download. Refresh it explicitly after validating newly downloaded data.
